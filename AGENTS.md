# Agent instructions

## Language

- Write all repository text in English: code, UI strings (pane labels, buttons, toasts, command descriptions), comments and READMEs, even when the conversation is in another language.

## Scope

This repository holds the plugins for the Herdr TUI (the terminal). Today that
is `ci-dash`.

The mods, layouts and themes for the Herdr desktop app live in a separate
repository,
[`herdr-mods`](https://github.com/dougcunha/herdr-mods). Do not add them here.
